## 2. 各项验收标准

1. **测速调度**：集成测试——两节点（一快一慢模拟：慢节点注入延迟/限流），运行期 `get_best_node` 随实测变化；评分变化有日志（脱敏）；禁用开关 `HYDRA_SPEEDTEST=0` 时评分保持现状
2. **流量统计**：E2E 传输 10MB 后 GUI/TrafficMonitor 读数与实际字节数一致（±1%）；`traffic` 既有单测保持
3. **STUN**：单测——合法响应解析/事务 ID 不匹配拒绝/错误格式拒绝（离线可测）；联机测试 `#[ignore]` 标注；/health 含 `public_addr` 字段（未配 STUN 时缺省）
4. **节点配置**：集成测试——toml 文件字段生效（listen/mode/key_file/health），优先级 CLI>env>file>默认；密钥文件 0600；非法字段显式报错退出
5. **BBR 开关**：单测——三种选择均正确构造 factory；非法值报错；未设=现状零改动
6. **V3.4 强制门**（不过不发布，降级即如实报告）：① `HYDRA_CHANNELS=4` 经 4 流通道传 1GB 数据校验和逐字节相等；② 传输中 reset 其中 1 条流：整体不中断（其余流接管）或显式失败回退普通路径（二选一，如实实现如实标注）；③ 未启用时代码路径逐位不变；④ 乱序窗口有界+超时兜底有测试
