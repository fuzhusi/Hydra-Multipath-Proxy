## 3. 关键设计决定

1. **send 契约核实**（B1 前置）：`PacketTransport::send(&self, buf: &[u8])` 返回借用 buf 的 future，三个实现（Tun2Transport/ChanDevice 队列/测试通道）均拷贝入队——**泵在 `send(..).await` 完成后复用 scratch 安全**。
2. **P0-1 不可回归**：就地版仍先写载荷后算校验和；`udp_reply_checksum_covers_payload_v4/v6` 与新增等价性测试（整段/逐字节/多段喂入、scratch 复用无残留）双重锁定。
3. **B4 最小侵入路线**：不动 `ChannelOpener` 跨 crate 契约；hydra-core 暴露 `ChannelOpenerAddr`（`Fn(SocketAddr, String) -> OpenFuture`），判定逻辑抽共用 `rule_open`，String 契约入口仅在原 `tun_rule_opener` 内 parse。旁路命中时**每连接零 parse 零分配**；未触发 Arc<str> 缓存降级。
4. **B3 生命周期**：frame_buf/keyed_buf 挂通道实例（单任务 `&mut self`），write 只借用切片、await 返回后即可下一轮构造；keyed 组装用 take/put-back 解决 `&mut self` 查表借用冲突（移动非分配）。
