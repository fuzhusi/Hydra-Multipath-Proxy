- **R1（P0）对比度**：text_faint 三主题重定——Dark `#9AA3B2`、Light `#767676`、Abyss `#6E86A8`（各对 bg_card ≥3:1）；bg_card_hover 派生对复检通过。
- **R2（P0）**：Light warning 加深至 `#B45309`（on bg_app ≥3:1）；Light success 正文用 `#047857`。
- **R3（P0）**：色板表补回现行 palette.rs 全部既有令牌（TEXT_ON_ACCENT、INFO/四组横幅 *_BG、BG_SIDEBAR/EXTREME/FAINT、BORDER_STRONG），新增 `text_disabled`、`splitter`、`shadow`、`accent_hover/pressed`、`chart_up/chart_down`；机械替换以完整表为唯一依据。
- **R4（P0）**：各主题显式 `text_on_accent`——Dark/Light 用深墨，Abyss 用深蓝黑 #0A1220（accent×白仅 1.86:1）。
- **R5（P0）**：`apply_theme(ctx)` 同步重写完整 egui::Visuals（widgets 三态/selection/separator/shadow/popup/图例轴样式）；T5 回归加「src 非 palette 文件不得残留字面量 Color32」grep 检查。
- **R6（P1）**：面积填充降级为**单色 30% alpha**（egui_plot 0.27 `Line::fill` 无原生渐变）；网格线亮度与 bg_card ≥1.15 相对差；图表保持禁用交互。
- **R7（P1）**：Hero 条三态规范——运行（success 描边+●绿+「停止代理」danger 按钮）/启动中（warning 描边+◐黄+按钮禁用）/停止（border 描边+○灰+「启动代理」accent 主按钮）；未配置节点引导卡置于 Hero 下；启动失败横幅用 DANGER_BG 横幅组件。
- **R8（P1）**：「当前节点」数据卡整卡可点跳转节点页（hover 描边 accent）。
- **R9（P1）**：快捷操作改**单行操作条**置于三卡与图表之间（图表沉底，保首屏纵向预算）。
- **R10（P1）**：字阶扩为六档——新增 22px「数据值」档（统计卡主数值），18px 保持页面标题；辅助 ≥12px、徽标 ≥11px 下限不变。
- **R11（P2）**：取色采用**零锁方案**——`AtomicU8` 主题种类 + 三套 `const Palette` 查表返回 `&'static`（无 RwLock、无 clone、每帧成本可忽略）。
- **R12（P2）**：启动首帧前从 config 恢复主题；侧栏/设置双入口共享同一持久化字段 `ui_theme`。

## 一、现状审计（使用者视角 + 设计师视角）

### 1.1 使用者视角（拿着截图问自己六个问题）

| # | 问题 | 现状答案 | 判定 |
|---|---|---|---|
| Q1 | 打开软件 3 秒内，我能知道代理是开是关吗？ | 「运行状态」藏在第一张卡片的一行文字里，与其他字段挤在一起 | ✗ 不显著 |
| Q2 | 我最关心的数据（流量/速率/节点）一眼能比出来吗？ | 四张卡平铺，标签+数值同字号同灰度，无视觉锚点 | ✗ 无层次 |
| Q3 | 速率图能告诉我"现在快不快"吗？ | 空态是一片黑色矩形 + 底部一行小字，像渲染坏了；有数据时也无网格/坐标/填充，读不出量级 | ✗ 图表失效 |
| Q4 | 我知道该在哪操作吗？ | 启动按钮与状态同卡片但视觉权重弱；快捷操作卡在页面最底（首屏外） | ✗ 操作埋没 |
| Q5 | 深色舒服吗？ | 全屏同一灰蓝色阶，卡片与背景对比 ~2:1，边界模糊，长时间看疲劳 | ✗ 对比不足 |
| Q6 | 界面好看吗？ | 字号层级只有 2-3 档、间距随机、无品牌色记忆点 | ✗ 无设计感 |

### 1.2 设计师视角（专业问题清单）

1. **设计令牌缺失**：`palette::` 全部是编译期 `const`，颜色无法运行时切换 → 三主题无从谈起（根因）。
2. **色彩体系**：无 60-30-10 法则配比；accent 蓝只出现在侧栏选中态；success/warning/danger 语义色使用随意。
3. **字阶混乱**：FONT_TITLE/FONT_BODY/FONT_SECONDARY 三档但使用不成体系（卡片标题、数值、标签字号对比不足）。
4. **间距系统**：SPACING_XS/SM/MD/LG 存在但卡片内部 padding、卡片间距、区块间距没有节奏（4/8/12/16/20 混用无规律）。
5. **图表设计不达标**：无网格线、无坐标轴、无面积填充、无双 y 轴语义（上下行同轴还行但无图例背景）、空态无设计。
6. **卡片层次**：所有卡片同一底色同一描边——主操作卡与信息卡无差异。
7. **信息架构**：首页 = 状态卡×4 + 图表卡 + 快捷操作卡，但"启动"这个核心动作埋在第一张卡内部。

### 3.2 字阶（4 档锁定）

- 数值大字 22px strong（统计卡主数值、状态字）
- 标题 15px strong（卡片标题/页面标题）
- 正文 13px
- 辅助 11px weak（标签/说明，且**一律大写或带 # 序号**增强锚点感）

### 3.3 间距节奏（4 的倍数）

卡片内 padding 16 / 卡片间 12 / 区块间 20 / 页边 20；圆角统一 10。

### 3.4 图表规范

- 背景：bg_card 同色（去掉独立黑色块）
- 网格：chart_grid 色、1px、横线 4 条纵线按 20 点间隔
- 曲线：上行 success 2px、下行 accent 2px，**下方 30% 透明渐变面积填充**
- 空态：居中图标 + 「启动代理后，这里会实时显示上下行速率」+ 次按钮引导
- 图例：内嵌左上角，带半透明底

### 3.5 首页信息架构（新）

```
┌────────────────────────────────────────────┐
│ Hero 条：状态圆点+大字状态 │ 主操作按钮 │ 监听摘要 │  ← 一级卡片（accent 描边强调）
├──────────────┬─────────────────────────────┤
│ 今日流量(大数) │ 活跃节点(大数) │ 当前节点(名称)   │  ← 二级：三张数据卡（数值 22px 主角）
├──────────────┴─────────────────────────────┤
│ 实时速率图（规范见 3.4）                        │  ← 三级
├────────────────────────────────────────────┤
│ 快捷操作（上移进首屏）                          │
└────────────────────────────────────────────┘
```

变更点：四卡改三卡（当前节点并入二级）、Hero 条独立承载主操作、快捷操作上移。
